# Kirab Akar Api Buka POPDA ke-15 Jatim di Ngawi

NGAWI – Kirab Akar Api bertajuk "Nyala dari Akar Ngawi" menandai pembukaan Pekan Olahraga Pelajar Daerah (POPDA) ke-15 dan Pekan Paralimpik Pelajar Daerah (PEPARPEDA) ke-3 Jawa Timur di Kabupaten Ngawi, Kamis (5/11/2026). Bupati Ngawi Ony Anwar Harsono menerima api tersebut.

Api dinyalakan di tungku tradisional di kawasan Ngawi Purba, yang dipandang sebagai asal-usul Kabupaten Ngawi. Kirab dimulai dari kantor desa Ngawi Purba, melewati kawasan perkotaan, dan berakhir di Pendopo Wedya Graha. Atlet pelajar berlari pada etape terakhir.

Tungku tradisional melambangkan sumber kehidupan dalam rumah tangga. Api yang dikirab melambangkan energi, ketekunan, dan kebersamaan dalam mengejar prestasi olahraga. Kirab juga dimaksudkan untuk memperkenalkan sejarah dan identitas Ngawi. Kegiatan ini hasil kolaborasi Dinas Pemuda dan Olahraga (Dispora) Provinsi Jawa Timur, Dispora Kabupaten Ngawi, dan pihak terkait.

Menurut Ony, jumlah peserta tahun ini lebih dari 8.000 atlet, naik dari sekitar 4.000 atlet pada penyelenggaraan sebelumnya. "Semangat dan antusiasme ini tentu kita apresiasi," ujarnya.

Ony juga menyinggung dampak ekonomi bagi daerah. Ia menyebut hotel banyak dipesan dan rumah warga dipakai sebagai tempat menginap peserta dan pendamping. "Dampaknya luar biasa. Perputaran ekonomi di Kabupaten Ngawi insyaallah juga akan luar biasa," katanya. Ia menambahkan semangat menggerakkan ekonomi kerakyatan lewat POPDA ke-15 sangat terasa.

Sebagai tuan rumah, Ngawi mendapat bantuan dari Pemerintah Provinsi Jawa Timur. Ony berterima kasih kepada Gubernur Jawa Timur yang mempercayakan penyelenggaraan kepada Ngawi.
