# Babinsa dan Warga Padamkan Titik Api di Batuputih Sumenep

SUMENEP – Babinsa Koramil 0827/15 Batuputih bersama warga memadamkan titik api di lahan sebelum api meluas, Rabu (11/11/2026). Kejadian berlangsung di Desa Bantelan, Kecamatan Batuputih, Kabupaten Sumenep.

Titik api ditemukan saat patroli Masyarakat Peduli Api (MPA). Babinsa Sigit Sugianto dan warga langsung memadamkannya tanpa menunggu api membesar. Sumber tidak menyebut luas lahan yang terbakar maupun penyebab munculnya api.

Menurut Sigit, kondisi lahan yang kering membuat api berpotensi merembet, sehingga patroli pencegahan perlu dilakukan sejak dini. "Tadi kami langsung bergerak bersama warga, karena kalau terlambat sedikit saja, api bisa merembet ke lahan lain," katanya.

Ia mengajak warga tidak menganggap remeh api sekecil apa pun. "Kalau menemukan api sekecil apapun, jangan dianggap sepele," ujarnya. Sigit menilai warga memiliki peran penting karena paling mengenal kondisi lahan di sekitarnya. "Masyarakat ini yang paling tahu kondisi lahannya," katanya.

Menurut Sigit, laporan cepat dari warga sangat membantu petugas. "Kalau warga cepat melapor, kami bisa cepat bergerak," ujarnya. Ia menambahkan pencegahan kebakaran tidak bisa hanya mengandalkan Babinsa. "Jadi pencegahan ini tidak bisa hanya mengandalkan Babinsa saja, harus bersama-sama," katanya.

Dalam kesempatan itu, warga diimbau tidak membakar sampah atau membuka lahan dengan cara dibakar, terutama saat musim kemarau. Jika melihat asap atau titik api, warga diminta segera melapor kepada Babinsa atau aparat desa terdekat.
